# ✦ Agent Dock Copilot - Microsoft Edge Side Panel Companion

Connect Microsoft Edge directly to your local **Agent Dock AI IDE & Ollama assistant**. 
Enables permanent Copilot-style browser side panel capabilities:
- **Permanent Side Panel**: Stays docked on the right side of Microsoft Edge (like Copilot / ChatGPT sidebar) — never auto-closes when clicking or typing anywhere on the page.
- **Direct Localhost Connection**: Communicates directly with the running Agent Dock app at `http://localhost:3000` — uses your local Ollama models and Agent Dock tools.
- **Read Active Page**: View, summarize, and extract code from any documentation or article you are viewing.
- **Save Code to PC**: Click "💾 Save to Agent Dock" to create files directly inside `~/AgentDock`.
- **Open Tabs**: Launch tabs, search the web, or navigate programmatically.
- **Sync to Agent Dock Cursor**: Push live page content directly into your IDE workspace context.

---

## 🚀 How to Install in Microsoft Edge (3 Steps)

1. Open **Microsoft Edge** and go to:
   ```text
   edge://extensions
   ```
2. In the bottom-left sidebar, switch **Developer mode** to **ON** (toggle the switch).
3. Click the **Load unpacked** button at the top, and select this folder:
   ```text
   ~/AgentDock\edge-extension
   ```

*(Or if you already loaded it earlier, simply click the 🔄 **Reload** icon next to "Agent Dock Copilot - Edge Side Panel" on `edge://extensions`).*

---

## 🌟 How to Open the Side Panel in Edge

- **Click the extension icon** in your Edge toolbar (or pin it):
  It automatically opens the permanent **Agent Dock Copilot Side Panel** on the right side of your browser.
- The side panel stays open permanently as you browse different websites, read articles, scroll, and click.
- When you switch tabs, the side panel automatically detects the new page title and domain!
